We are implementing SaaS Option 1: exactly ONE Boat Profile per Account (tenant). This Boat Profile is the single source of truth for boat configuration (branding, home port, sails). Account remains the tenant; BoatProfile is the domain configuration. Do NOT duplicate boat name/home port into trips or logbook entries (no redundancy). Only store per-trip overrides in the future if needed.

Stack: FastAPI + SQLAlchemy + Jinja/HTMX. i18n exists (t() + locales/de.json + locales/en.json). Any NEW UI strings must use t() keys.

PHASE: Implement Boat Profile module + dynamic header branding + optional home port + sail-aware “Sail Change” log entries.

========================
1) DATABASE (MIGRATIONS)
========================
Create two new tables and extend logbook entry storage.

1.1 boat_profiles (1:1 with accounts)
- id SERIAL PK
- account_id INT UNIQUE NOT NULL FK -> accounts.id
- boat_name VARCHAR(100) NOT NULL
- home_port_name VARCHAR(100) NULL
- home_port_lat DOUBLE PRECISION NULL
- home_port_lon DOUBLE PRECISION NULL
- boat_make VARCHAR(100) NULL
- boat_model VARCHAR(100) NULL
- boat_year INT NULL
- created_at TIMESTAMP DEFAULT now()
- updated_at TIMESTAMP DEFAULT now()

1.2 sail_profiles (1:1 with boat_profiles)
- id SERIAL PK
- boat_profile_id INT UNIQUE NOT NULL FK -> boat_profiles.id
- main_type VARCHAR(20) NOT NULL DEFAULT 'FURLING'   (allowed: FURLING, SLAB_REEFING)
- main_reef_levels INT NOT NULL DEFAULT 2            (relevant for SLAB_REEFING)
- headsail_genoa BOOL NOT NULL DEFAULT true
- headsail_jib BOOL NOT NULL DEFAULT false
- headsail_furling BOOL NOT NULL DEFAULT true
- has_code0 BOOL NOT NULL DEFAULT false
- has_gennaker BOOL NOT NULL DEFAULT false
- has_spinnaker BOOL NOT NULL DEFAULT false
- created_at TIMESTAMP DEFAULT now()
- updated_at TIMESTAMP DEFAULT now()

(Keep sail_profiles simple: use VARCHAR + check constraint if easy, or Python enum mapped to VARCHAR. Avoid complex Postgres enum migrations unless the project already uses them cleanly.)

1.3 Extend logbook entry table (whatever your table is named, e.g. logbook_entries)
Add nullable columns to store structured sail state for sail-change maneuver entries:
- main_furl_percent INT NULL           (0..100)
- main_reef_level INT NULL             (0,1,2)
- headsail_type VARCHAR(10) NULL       (NONE, GENOA, JIB)
- headsail_furl_percent INT NULL       (0..100)
- extra_sail VARCHAR(10) NULL          (NONE, CODE0, GENNAKER, SPINNAKER)

Add lightweight constraints if safe:
- CHECK main_furl_percent between 0 and 100 when not null
- CHECK headsail_furl_percent between 0 and 100 when not null

Backfill / bootstrap:
- For Account 1: create boat_profile with boat_name='WAGMI' and home_port_name='Fredericia' (data only).
- Create sail_profile for that boat_profile with main_type='FURLING', headsail_genoa=true, headsail_furling=true (reasonable default).
- For other accounts: do not auto-create in migration; create lazily on first access to Boat Setup page. Header must handle missing boat_profile gracefully.

8) LOGBOOK: SAIL CHANGE MANEUVER (SAIL-AWARE UI + STORAGE)
========================
Add/extend the “Sail Change” maneuver entry UI to store structured sail state.

8.2 UI logic (conditional based on sail_profile):
On the Sail Change entry form:
- Mainsail:
  - If main_type == FURLING: show slider main_furl_percent 0–100
  - If main_type == SLAB_REEFING: show selector main_reef_level: 0 (none), 1 (reef 1), 2 (reef 2)
  - Never show both.
- Headsail:
  - Dropdown headsail_type based on inventory:
    - if genoa enabled: GENOA option
    - if jib enabled: JIB option
    - always NONE option
  - If headsail_furling true AND headsail_type != NONE: show slider headsail_furl_percent 0–100
- Extra sail:
  - If any of has_code0/has_gennaker/has_spinnaker true: show dropdown extra_sail:
    - NONE always
    - CODE0/GENNAKER/SPINNAKER only if enabled
  - Else hide field.

8.3 Save logic:
- When saving entry:
  - If main_type == FURLING: save main_furl_percent, set main_reef_level=NULL
  - If SLAB_REEFING: save main_reef_level, set main_furl_percent=NULL
  - If headsail_type == NONE: set headsail_furl_percent=NULL
  - If no extra_sail: save NONE or NULL (choose consistent; prefer NULL for “not set”, but if your UI expects “NONE” use NONE)

8.4 Display:
- In logbook list/timeline, for Sail Change entries show compact summary lines using t() keys:
  - Main: “70%” or “Reef 1”
  - Headsail: “Genoa 80%” etc.
  - Extra: “Code 0”

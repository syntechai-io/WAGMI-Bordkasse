Projektziel (Kurzfassung)
Baue eine minimalistische, produktionsnahe Bordkassen-Webapp für einen Segeltörn (Crew-Wallet). Anforderungen:
	•	Gemeinsame Wallet (Einzahlungen pro Crewmitglied)
	•	Ausgaben mit Split-Modi equal (alle) oder participants (explizite Teilmenge)

	•	Einfaches Login (nur Admin + Optional: PIN-Gate für Crew)
	•	Technik: Python FastAPI, SQLite (SQLAlchemy), Jinja2 + HTMX + TailwindCSS; kein externer Dienst nötig

Geschäftslogik
	1.	Wallet-Saldo = Summe aller Deposits – Summe aller Ausgaben, die paid_from = wallet.
	2.	Bezahlte Summe pro Person = Summe aller Expense.amount_eur, bei denen payer_id = Person (unabhängig von paid_from).
	3.	Anteil pro Person je Expense
	•	equal: Betrag / Anzahl Crewmitglieder (oder optional nur aktive)
	•	participants: Betrag / Anzahl der in ExpenseParticipant verknüpften Personen
	4.	Gesamter „Share Owed“ pro Person = Summe ihrer Anteile über alle Expenses.
	5.	Netto = (Bezahlte Summe + ggf. eigene Einzahlungen?) – Share Owed.
	•	Für Transparenz: Deposits fließen nicht direkt in Netto je Person ein, sondern in den Wallet-Saldo. Die Netto-Abrechnung basiert auf „wer hat bezahlt“ vs. „wer schuldet Anteile“. Das ist robust, egal ob „wallet“ oder „private“ gezahlt wurde.
	6.	Ausgleichsvorschlag (Settlement): Greedy-Match
	•	Liste creditors (Netto > 0) und debtors (Netto < 0, Betrag positiv gedacht) absteigend sortieren
	•	immer min(debtor, creditor) ausgleichen, bis eine Seite 0 ist
	•	Ausgabe als Tabelle „Von → An → Betrag“

settlement-Logik (als Funktion)

def compute_settlement(net_map: dict[str, float]) -> list[tuple[str, str, float]]:
    """
    net_map: person_code -> net amount (positive: should receive; negative: should pay)
    Returns list of (from_code, to_code, amount) minimal greedy.
    """
    creditors = [(c, a) for c, a in net_map.items() if a > 0.01]
    debtors = [(c, -a) for c, a in net_map.items() if a < -0.01]
    creditors.sort(key=lambda x: x[1], reverse=True)
    debtors.sort(key=lambda x: x[1], reverse=True)
    out = []
    i = j = 0
    while i < len(debtors) and j < len(creditors):
        d_code, d_amt = debtors[i]
        c_code, c_amt = creditors[j]
        pay = round(min(d_amt, c_amt), 2)
        if pay > 0:
            out.append((d_code, c_code, pay))
        d_amt -= pay
        c_amt -= pay
        if d_amt <= 0.01: i += 1
        else: debtors[i] = (d_code, d_amt)
        if c_amt <= 0.01: j += 1
        else: creditors[j] = (c_code, c_amt)
    return out

Upload-Route (Ausschnitt)

@router.post("/expenses/{expense_id}/receipts/upload")
async def upload_receipt(expense_id: int, file: UploadFile = File(...), admin=Depends(require_admin)):
    allowed = {"application/pdf","image/jpeg","image/png"}
    if file.content_type not in allowed:
        raise HTTPException(status_code=415, detail="Nur PDF/JPG/PNG erlaubt.")
    content = await file.read()
    if len(content) > 10 * 1024 * 1024:
        raise HTTPException(status_code=413, detail="Datei zu groß (>10MB).")
    ext = ".pdf" if file.content_type=="application/pdf" else (".jpg" if file.content_type=="image/jpeg" else ".png")
    uid = str(uuid.uuid4()) + ext
    path = Path("uploads")/uid
    path.write_bytes(content)
    # DB: Receipt anlegen (stored_filename=uid, original_name=file.filename, content_type, size_bytes=len(content))
    return RedirectResponse(url=f"/expenses/{expense_id}", status_code=303)

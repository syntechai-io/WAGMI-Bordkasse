### FIX 1 — Night mode: add `--cl-*` token bridge so all cl_design.css components respect the nautical red palette

**Note to Replit**: The red-on-black night mode is INTENTIONAL for nautical use (preserves dark-adapted vision at sea). Do NOT change it to blue/navy. Just ensure the `--cl-*` tokens map to the same palette.

### FIX 2 — Time input too tall on iPhone (Day Recap form)

**Root cause**: `<input type="time">` on iOS Safari and Chrome uses the native time picker chrome, rendering ~72–88px tall by default. The current `.cl-input` style sets `min-height: 44px` but does not override `max-height` or suppress the webkit default height expansion.

**Edit `static/ui_ios_prime.css`** — inside the existing `@media (max-width: 1023px)` block, add:

```css
/* ── time input: cap native iOS height ── */
input[type="time"] {
  -webkit-appearance: none;
  appearance: none;
  height: 48px !important;
  max-height: 48px !important;
  min-height: 48px !important;
  padding: 0 14px !important;
  line-height: 48px !important;
  font-size: 16px !important;
  border-radius: var(--cl-radius-sm, 10px) !important;
  border: 1.5px solid var(--cl-border) !important;
  background: var(--cl-surface) !important;
  color: var(--cl-text) !important;
  width: 100% !important;
  box-sizing: border-box !important;
}
```

Also add **globally** (outside any media query) in the same file:

```css
/* Prevent native picker from blowing up on any device */
input[type="time"] {
  -webkit-appearance: none;
  appearance: none;
  max-height: 52px;
}
```

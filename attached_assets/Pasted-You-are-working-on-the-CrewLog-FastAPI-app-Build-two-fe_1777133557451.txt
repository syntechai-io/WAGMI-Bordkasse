    @app.post("/set-mode")
    async def set_app_mode(request: Request, mode: str = Form(...)):
        """Toggle between 'full' and 'logbook' app modes. Stored in session."""
        from fastapi.responses import RedirectResponse
        if mode in ("logbook", "full"):
            request.session["app_mode"] = mode
        referer = request.headers.get("referer", "/")
        return RedirectResponse(url=referer, status_code=303)

─────────────────────────────────────────────────────────────────────────────

In static/js/logbook-gps.js, add wake lock support to prevent iOS from
sleeping and killing GPS tracking. Make these changes:

1. In the constructor, add:

2. In the start() method, after `this.isTracking = true;`, add:
       this._requestWakeLock();

3. In the stop() method, after `this.isTracking = false;`, add:
       this._releaseWakeLock();

4. Add these two methods to the class (before the closing brace):

    async _requestWakeLock() {
        if ('wakeLock' in navigator) {
            try {
                this.wakeLock = await navigator.wakeLock.request('screen');
                this.wakeLock.addEventListener('release', () => {
                    this.wakeLock = null;
                });
            } catch (e) {
                // Wake lock not granted — acceptable, tracking continues
            }
        }
    }

    _releaseWakeLock() {
        if (this.wakeLock) {
            this.wakeLock.release().catch(() => {});
            this.wakeLock = null;
        }
    }

STEP 2E — Handle heading averaging correctly (fix potential null issue)
─────────────────────────────────────────────────────────────────────────────

In static/js/logbook-gps.js, find the getAveragedPosition() method.
The heading average is wrong when some entries have heading=null (iOS often 
returns null heading when stationary). Fix the average to skip null values:

Replace the heading sum/average logic with:

    getAveragedPosition() {
        if (this.positionHistory.length === 0) return null;

        let latSum = 0, lonSum = 0, speedSum = 0, speedCount = 0;
        let headingSum = 0, headingCount = 0;

        this.positionHistory.forEach(pos => {
            latSum += pos.coords.latitude;
            lonSum += pos.coords.longitude;
            if (pos.coords.speed !== null && pos.coords.speed >= 0) {
                speedSum += pos.coords.speed;
                speedCount++;
            }
            if (pos.coords.heading !== null && pos.coords.heading >= 0) {
                headingSum += pos.coords.heading;
                headingCount++;
            }
        });

        const count = this.positionHistory.length;
        return {
            latitude:  latSum / count,
            longitude: lonSum / count,
            speed:     speedCount > 0 ? speedSum / speedCount : null,
            heading:   headingCount > 0 ? headingSum / headingCount : null,
        };
    }
